# Style Guidelines
- Function names should be camelCase starting with a lowercase letter
- Object names should be CamelCase starting with an uppercase letter
- Variable names should be camelCase starting with a lowercase letter
- Number of characters in single line should _never_ exceed 80 chars
- File names should be camelCase starting always from uppercase letter
- directories should be camelCase starting always from lowercase letter
- Exceptions (keep exact filenames): ARCHITECTURE.md, README.md, STYLE.md,
  LICENSE, CHANGELOG.md, FUNDING.yml

Anything else should follow the guidance 
in [this style guide](https://github.com/luarocks/lua-style-guide)
